# TasksHive

TasksHive - A task management application built with React and Node.js.

## Features

- **Task Management**
  - Create, edit,, update and delete tasks
  - Mark tasks as completed
  - Archive tasks
  - Mark important tasks

- **Task Filtering**
  - Filter tasks by status (Active, Completed, Archived, Important)
  - Quick access to different task views

## Tech Stack

- **Frontend**
  - React.js
  - Tailwind CSS
  - React Icons

- **Backend**
  - Node.js
  - Express.js
  - MongoDB

## Getting Started

### Prerequisites

- Node.js
- MongoDB

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yogayataverma/TaskHive.git
   cd TaskHive
   ```

2. Install dependencies:
   ```bash
   cd server
   npm install

   cd ../client/taskhive
   npm install
   ```

3. Set up environment variables:
   - Create a `.env` file in the server directory
   - Add necessary environment variables like PORT and MONGO_URI

4. Start the development servers:
   ```bash
   npm run dev
   ```
